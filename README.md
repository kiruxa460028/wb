# WB Supply Planner (Web)

Интерфейс и функциональность переработаны под полный дашборд в стиле макета.

## Реализованные блоки

- Авторизация (вход/регистрация/выход) перед доступом к дашборду.
- Hero + KPI-карточки.
- API-only режим (загрузка XLSX отчета и файлов поставок убрана из интерфейса).
- Главный экран теперь дашборд кабинета:
  - маркеры покрытия;
  - мини-отчет top-15 по заказам;
  - кнопка перехода "Рассчитать поставку".
- Добавлена отдельная страница "Аналитика":
  - общая информация по остаткам;
  - фильтр по категориям;
  - сортировка (по заказам/покрытию);
  - маркеры покрытия.
- В настройках добавлена отдельная вкладка "Маркеры" для порогов покрытия.
- Все фильтры и кнопки расчета вынесены на отдельную страницу "Расчет поставки".
- API настраивается через меню пользователя (справа сверху): "Настройки" → токен/API actions.
- Поиск, фильтр по складу, режимы МСК (объединить/исключить).
- Рекомендации к поставке:
  - метод по выкупам / заказам;
  - запас на N дней;
  - дата поставки;
  - округление;
  - скрытие поставок `<5`.
- Правая панель сводки:
  - итого к отгрузке;
  - итого коробов;
  - дата поставки;
  - donut-индикатор.
- Вкладки:
  - отчет по остаткам;
  - рекомендации к заказу;
  - ABC-анализ;
  - перераспределение.
- Прогнозный график на 60 дней (остаток vs спрос).
- Экспорт расчета в CSV/XLSX.
- Блок "Тест API WB": проверка токена read-only по GET endpoint (stocks/orders/sales/incomes).
- Кнопка "Загрузить остатки": забирает `Stocks` из API (GET only) и показывает в таблице отчета в том же формате.
- Кнопка "Загрузить остатки" теперь подтягивает `Stocks + Orders` (GET only), чтобы считать покрытие по заказам.
- Загрузка из API теперь использует `Stocks + Orders + Sales`:
  - считает `% выкупа` по каждому товару;
  - учитывает остатки `в пути` из `Stocks` (`inWayToClient + inWayFromClient`) в общем остатке.
- Пороги аналитики настраиваются в UI:
  - `Low stock` по умолчанию `< 20` дней.
  - `Overstock` по умолчанию `> 45` дней.
- Отчет по остаткам по умолчанию показывает общий итог по артикулу; детализация по складам включается кнопкой.
- API токен привязывается к текущему локальному пользователю и подставляется автоматически.
- Автообновление API каждые 20 минут (если токен сохранен).
- Кнопки API ограничены: не чаще 1 нажатия в 10 секунд.

## Файлы

- `index.html` - полный интерфейс
- `styles.css` - новый дизайн
- `js/app.js` - вся бизнес-логика (совместимо с запуском через `file://`)

## Быстрый запуск

1. Откройте `index.html` в браузере.
2. Создайте аккаунт на экране входа и авторизуйтесь.
3. Откройте "Настройки" в меню пользователя и вставьте API токен WB.
4. Нажмите "Загрузить остатки".
5. Перейдите на страницу "Расчет поставки".

## Важно по авторизации

- Это локальная авторизация для текущего прототипа.
- Пользователи хранятся в `localStorage`, сессия — в `sessionStorage`.
- Для production нужна серверная авторизация (backend + БД + JWT/cookie).
