## 🎯 Что это

Веб-кабинет для селлера Wildberries. Забирает остатки, заказы и продажи через
Statistics API, считает покрытие в днях и выдаёт готовый список «что и сколько
везти на склад».

Приложение работает **без сборщиков и npm-зависимостей**: это статический
фронтенд (`web/`) плюс лёгкий сервер, который отдаёт эту статику и хранит
пользовательские данные в SQLite.

```
Браузер  ──►  web/index.html + css + js        (интерфейс, расчёты)
              │
              ├──►  /api/auth/*        вход и регистрация
              ├──►  /api/user-data/*   настройки, кэш, резервные копии
              └──►  /api/wb/proxy      запросы к Wildberries API
                            │
                            └──►  statistics-api.wildberries.ru
```

## ✨ Возможности

| Раздел | Что внутри |
|---|---|
| 🔐 **Авторизация** | Вход, регистрация, несколько кабинетов на одного пользователя |
| 📊 **Дашборд** | KPI (остаток, прогноз 30 дней, оборачиваемость, % выкупа), маркеры покрытия, топ-15 по заказам, график за месяц |
| 📈 **Аналитика** | Остатки, склады, оборачиваемость за 14 дней, графики по артикулам, фильтры и сортировки |
| 🧮 **Расчёт поставки** | Метод по заказам или выкупам, запас на N дней, дата поставки, округление, доли по складам, режимы МСК |
| 🗂 **Отчёты** | Поставка, отчёт по остаткам, ABC-анализ, перераспределение между складами |
| 🔌 **WB API** | Проверка токена, загрузка `Stocks + Orders + Sales`, автообновление раз в 20 минут |
| 💾 **Импорт / экспорт** | Импорт CSV, экспорт расчёта в CSV и XLSX |
| ⚙️ **Настройки** | Токен API, пороги маркеров покрытия, фильтры и план |

│   └── sample-sales-report.xlsx

├── deploy/                     🚀 конфиги хостинга
│   ├── .envrc                     окружение Node на хостинге
│   └── tmp/restart.txt            триггер перезапуска Passenger
│
├── docs/                       📚 документация
│   ├── STRUCTURE.md               что где лежит и зачем
│   ├── API.md                     справочник HTTP-эндпоинтов
│   ├── DEPLOY.md                  деплой на хостинг и сборка EXE
│   └── MIGRATION.md               карта переноса файлов

> Раньше оба файла назывались `app.js` и лежали рядом в корне; теперь они разведены по папкам.

## 🚀 Быстрый старт

### Вариант 1 — Node (рекомендуется)

```bash
node server/server.js
# → http://127.0.0.1:5500
```

Требуется **Node.js 22+** (используется встроенный модуль `node:sqlite`).

### Вариант 2 — Python

```bash
python3 server/server.py
# → http://127.0.0.1:5500
```

Требуется **Python 3.10+**, внешних пакетов не нужно — только стандартная библиотека.

### Настройка хоста и порта

```bash
HOST=0.0.0.0 PORT=8080 node server/server.js
HOST=0.0.0.0 PORT=8080 python3 server/server.py
```

### Первый запуск

1. Откройте `http://127.0.0.1:5500`.
2. Создайте аккаунт на экране входа.
3. Меню пользователя → **Настройки** → вставьте токен Wildberries API.
4. Нажмите **Загрузить остатки**.
5. Перейдите в раздел **Расчёт поставки**.

## 🔀 Два бэкенда: какой выбрать

Оба сервера отдают один и тот же интерфейс из `web/` и работают с одной базой
`data/app.db`, но умеют разное:

| Возможность | `server/server.js` (Node) | `server/server.py` (Python) |
|---|:---:|:---:|
| Раздача фронтенда | ✅ | ✅ |
| Вход и регистрация | ✅ | ✅ |
| Чтение и запись данных пользователя | ✅ | ✅ |
| Массовая синхронизация | ✅ | — |
| Резервные копии и восстановление | ✅ | — |
| Перенос локального профиля | ✅ | — |
| Прокси к Wildberries API | — | ✅ |
| Зависимости | Node 22+ | только стандартная библиотека |

**Как выбрать:**

- **Node** — для хостинга и повседневной работы: полный набор функций, резервные копии.
- **Python** — если нужен серверный прокси к WB API (обходит CORS и «белые списки» IP)
  или если вы собираете десктопный EXE.

> Если `/api/wb/proxy` недоступен, фронтенд автоматически переключается на прямые
> запросы к WB API из браузера — интерфейс продолжает работать.

Полный список эндпоинтов — в [docs/API.md](docs/API.md).

## 🖥 Десктопная версия

Автономный калькулятор поставок на tkinter — без интернета и без API:

```bash
python3 desktop/wb_supply_calculator.py
```

Формула: `потребность = продажи/день × (срок доставки + покрытие + страховой запас) − текущий остаток`,
с округлением до целых коробов. Пример входного файла — [`samples/example_import.csv`](samples/example_import.csv).

Сборка в `.exe` для Windows:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_exe.ps1
```

## 🔒 Данные и безопасность

- База `data/app.db` (таблицы `users`, `user_data`, `user_data_backups`) **исключена из Git**
  — в ней лежат хэши паролей и токены WB API.
- Пароли хранятся как PBKDF2-SHA256, 120 000 итераций, со случайной солью.
- Прокси к WB API пропускает **только GET-запросы** и только на
  `statistics-api.wildberries.ru`.

> ⚠️ Авторизация рассчитана на локальный запуск и доверенную сеть: сессия живёт
> на стороне браузера, серверных сессий и JWT пока нет. Перед публикацией в
> интернет добавьте HTTPS и серверные сессии.
