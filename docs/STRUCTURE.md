## 🎨 `web/` — интерфейс

Статика без сборщика: никакого npm, webpack или транспиляции. Файлы
отдаются как есть, поэтому правки видны сразу после перезагрузки страницы.

| Файл | Размер | Назначение |
|---|---|---|
| `index.html` | ~450 строк | Разметка всех экранов: авторизация, топбар, дашборд, аналитика, расчёт поставки, настройки, мобильное меню |
| `css/styles.css` | ~1800 строк | Дизайн-система (токены в `:root`) и стили всех компонентов |
| `js/app.js` | ~4500 строк | Единый IIFE: состояние, запросы к API, расчёты, отрисовка таблиц и графиков |

**Внешние зависимости** подключаются из CDN прямо в `index.html`:

- [SheetJS 0.18.5](https://sheetjs.com) — чтение и запись XLSX;
- Google Fonts — шрифты Manrope и IBM Plex Sans.

### Как устроен `css/styles.css`

```
1. Дизайн-токены (:root)      цвета, отступы, тени, скругления
2. Reset и база               типографика, фон, скроллбар
3. Экран авторизации
4. Топбар и навигация
5. Layout, панели, hero, KPI
6. Формы, кнопки, вкладки, таблицы
7. Сайдбар расчёта, модалки
8. Мобильное меню и адаптив
```

Меняйте цвета и отступы через переменные в `:root` — они подхватываются
всеми компонентами сразу.

### Как устроен `js/app.js`

Весь код обёрнут в одну IIFE, чтобы не засорять глобальную область:

| Блок | Что делает |
|---|---|
| `el` | Ссылки на DOM-элементы (один раз при старте) |
| `state` | Текущий кабинет, загруженные данные, настройки, режимы |
| `switchPage` / `activateTab` | Переключение разделов и вкладок |
| Загрузка данных | Запросы к WB API, разбор ответов, кэш |
| Расчёты | Покрытие, оборачиваемость, ABC, перераспределение, рекомендации |
| Отрисовка | Генерация таблиц, маркеров, графиков на `<canvas>` |
| Экспорт | CSV и XLSX |

## ⚙️ `server/` — бэкенд

Две независимые реализации одного приложения. Обе отдают `web/` и пишут в
`data/app.db`. Запускать нужно **только одну** — они занимают один порт.

### `server.js` — Node.js 22+

- Встроенный `node:sqlite` — внешних пакетов не нужно.
- Авторизация, данные пользователя, синхронизация, резервные копии.
- Эндпоинты Ozon оставлены заглушками (API отключён, данные грузятся отчётами).
- Статика: `../web`, база: `../data/app.db`.

### `server.py` — Python 3.10+

- Только стандартная библиотека (`http.server`, `sqlite3`, `hashlib`).
- Авторизация и данные пользователя.
- **Прокси к Wildberries API** — единственное место, где он реализован.
- Используется как основа для десктопного EXE.

Общие переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `HOST` | `127.0.0.1` | Интерфейс для прослушивания |
| `PORT` | `5500` | Порт |
| `WBSP_DATA_DIR` | `<корень>/data` | Папка с базой (только Node) |
| `WBSP_DB_PATH` | `<корень>/data/app.db` | Путь к базе (только Python) |
| `WBSP_NO_BROWSER` | — | `1` — не открывать браузер (только Python) |

## 🔒 `data/` — вне Git

SQLite-база `app.db` создаётся автоматически при первом запуске.

| Таблица | Содержимое |
|---|---|
| `users` | Логин, соль, PBKDF2-хэш пароля |
| `user_data` | Настройки, токены API, кэш данных, названия товаров — по ключам вида `<тип>:<пользователь>::<кабинет>` |
| `user_data_backups` | Снимки данных пользователя (хранится последние N) |

Папка добавлена в `.gitignore`: база содержит **хэши паролей и токены WB API**,
её нельзя коммитить.
